# red-sand-rally

A clean-room, from-scratch re-implementation of the idea behind **[tao716/red-sand-rally](https://github.com/tao716/red-sand-rally)** by [@tao716](https://github.com/tao716). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
